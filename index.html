For grown-ups

Asteroid Run is a free practice game for the Year 4 Multiplication Tables Check: 25 questions per mission, from gentle 12-second levels up to the official 6 seconds, with a 3-second gap between questions.

We store only what the game needs: a username and PIN to sign in (no email, no real name), and each mission's answers and times so the flight log can show which facts need practice. Other players only ever see a pilot's callsign, which is built from fixed word lists, plus their scores.

Delete a pilot and everything saved for it any time in Settings → Delete this pilot.
